
# Arabic Technology News Classification

## Project Overview

This project focuses on classifying Arabic technology news articles
into predefined categories using Natural Language Processing (NLP)
and a T5-based deep learning model.

The model analyzes the text of an Arabic news article and predicts
its category.

## Project Objectives

- Process and clean Arabic technology news articles.
- Prepare the dataset for model training.
- Fine-tune a T5-based model for text classification.
- Evaluate the model using classification metrics.
- Predict categories for new Arabic news articles.

## Technologies Used

- Python
- Google Colab
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- Scikit-learn
- Gradio

## Dataset

The dataset contains Arabic technology news articles.

The model uses article text as input and the corresponding category
as the prediction target.

The original dataset is not included in this repository.

## Model Training

The notebook includes the data preparation, model configuration,
training, evaluation, and prediction steps.

Training may require a GPU and significant computing resources.

## How to Use

1. Open the notebook in Google Colab.
2. Prepare the dataset in the required format.
3. Install the required Python libraries.
4. Configure the dataset and model paths.
5. Run the notebook cells in the correct order.
6. Train or load the model and evaluate its predictions.

## Limitations

The notebook may require adjustments to file paths, library versions,
and dataset formats before it can run in a new environment.
